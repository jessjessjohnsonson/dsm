# dsm
Network analyses of the DSM (currently only version 5 from 2018) diagnostic classes and criteria.

# Data collection and cleaning
1. Downloaded DSM-5 criteria data from this OSF repository: https://osf.io/r5vqk/ (Data_for_supplement.xlsx)
2. Added column "Repeats within primary diagnostic criteria" to identify criteria that repeated within the primary diagnosis criteria (as opposed to "Repeats At All", which included specifiers).
3. Added columns "Criterion Name" and "Criterion Category" to provide single name for criteria identified as duplicates in original data (identified by unique identifier with varying names using original language from DSM-5), as well as group criteria by higher-level categories.
